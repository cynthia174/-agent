# AI 销售数据分析 Agent

一个面向销售与电商数据的自然语言分析工具。用户上传 Excel 或 CSV 销售表后，可以直接用中文提问。系统会理解问题、制定受控的分析计划、执行真实数据计算、检查结果，并按需生成图表。

所有业务数字都由本地数据计算产生，AI 只参与理解问题和制定分析方法，不直接编造答案。

## 主要功能

- 上传并读取 Excel、CSV 销售数据；
- 自动识别日期、地区、产品、品类、客户类型、销售额、成本、折扣和数量；
- 使用自然语言查询总额、平均值、排名、分组对比和时间趋势；
- 展示每一步的分析方法、运行结果和检查状态；
- 计算失败后根据错误信息自动调整计划，最多尝试 3 次；
- 外部 AI 不可用时自动进入本地分析模式；
- 生成柱状图和月度趋势图，并保存为 PNG 图片；
- 最终答案固定包含“答案、依据、步骤数”；
- 提供自动化回归检查，验证计算准确性、错误处理和运行时限。

## 可以询问的问题

- `去年总营收是多少？`
- `哪个地区营收最高？`
- `营收最高的前三个产品是什么？`
- `哪个地区的平均折扣最高？`
- `哪个月营收最高？`
- `各产品类别的利润分别是多少？`
- `营收最高的前三个产品是什么？顺便画张柱状图。`
- `帮我画一下每个月营收趋势。`
- `不同地区的营收对比图。`

## Agent 内部运行逻辑

每个问题都会进入一个有最大次数限制的分析循环：

```text
读取数据
   ↓
理解时间、指标、分组和图表需求
   ↓
生成受限制的分析计划
   ↓
在数据表上执行真实计算
   ↓
检查结果是否为空或包含无效数字
   ├─ 正常：生成答案或图表
   └─ 失败：读取错误 → 修正计划 → 重新计算
                              （最多尝试 3 次）
```

分析计划只允许使用预先定义的指标、分组字段和汇总方式，不执行 AI 任意生成的代码。这让计算过程更加安全、稳定，也便于审计。

以“哪个地区的平均折扣最高？”为例：

1. 识别指标为“折扣”、分组为“地区”、方法为“平均值”；
2. 按地区对真实订单进行分组；
3. 计算各地区平均折扣；
4. 从高到低排序；
5. 检查结果后输出结论、计算依据和步骤数。

## 自动纠错

页面左侧提供“演示一次自动纠错”开关。开启后，系统会让第一次计划使用一个不存在的字段，以完整展示：

1. 第一次计算失败；
2. 显示具体错误原因；
3. 根据问题重新识别正确字段；
4. 第二次执行真实计算；
5. 检查通过并给出答案。

即使正常使用时不开启该开关，Agent 遇到外部 AI 返回无效计划、字段不存在或图表生成失败时，也会进入同一套有限次数的修正流程。

## 图表能力

图表使用计算后的汇总数据生成，而不是由 AI 直接绘制虚构数字。

- 产品、地区和品类对比使用柱状图；
- 月度变化使用趋势折线图；
- 图片以 PNG 格式保存到 `charts/`；
- 最终答案会返回图片的绝对保存位置；
- 画图失败时会显示原因，并使用更通用的图表方式重试一次。

## AI 模式与本地模式

- 配置 Evolink API Key：由 AI 负责把自然语言转换成受控分析计划，本地程序负责计算。
- 不配置 Key：自动使用本地规则理解常见问题，所有计算与图表功能仍可运行。
- AI 接口失败：显示接口错误并自动切换到本地模式。

无论使用哪种模式，最终数字始终来自上传的数据表。

## 快速运行

Windows 用户可以直接双击：

```text
启动项目.bat
```

第一次启动会自动创建独立运行环境并安装依赖。浏览器通常会自动打开；如果没有，请访问：

```text
http://localhost:8501
```

也可以使用命令运行：

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

## 配置 AI Key

不填写 Key 也可以使用本地分析模式。如需启用 AI 规划：

1. 复制 `.env.example` 并重命名为 `.env`；
2. 在 `EVOLINK_API_KEY=` 后填写自己的 Key；
3. 不要提交 `.env`，项目已经通过 `.gitignore` 排除该文件。

也可以在页面左侧的密码输入框中临时填写 Key。

## 自动检查

双击 `运行自动检查.bat`，或运行：

```bash
.venv\Scripts\python.exe run_checks.py
```

当前检查覆盖：

- 销售表读取和九个必要字段；
- 总营收、地区排名、产品前三名；
- 平均折扣和最高营收月份；
- 利润与月度趋势计算；
- PNG 图表生成；
- 缺列和无数据时的明确错误提示；
- 第一次失败后的自动修正；
- 最大步骤数和运行时间限制；
- 最终答案是否包含结论、依据和步骤数。

## 迭代过程

### 第一阶段：数据读取与基础计算

建立统一的数据字段规范，支持 Excel 和 CSV，完成总营收、地区排名、产品排名等基础问题的真实计算。

### 第二阶段：字段理解与准确性修正

在自动检查中发现“产品类别”可能被提前识别成“产品”，随后将匹配方式调整为优先识别更具体、更长的字段名称，并加入对应回归检查。

### 第三阶段：错误处理与质量检查

加入缺列、空年份、空问题等异常场景，确保程序返回可读错误而不是直接退出；同时增加运行时间和步骤数量检查，防止重复执行。

### 第四阶段：有限步 Agent 循环

将单次计算升级为“理解 → 规划 → 执行 → 检查 → 修正”的循环。增加最大 3 次尝试限制、AI 失败自动降级和固定答案格式。

### 第五阶段：图表与结果交付

加入产品柱状图、地区对比图和月度趋势图，将图片保存为 PNG，并把保存位置写入最终答案。图表生成失败时会显示错误并尝试更通用的绘图方式。
